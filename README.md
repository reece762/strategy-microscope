# 策略顯微鏡 · 策略回測庫

把影片裡講的選股與擇時策略，用美股 55 年、加密貨幣 9 年的日線資料重新跑一次，看它們在今天的市場還站不站得住。

**線上瀏覽**：https://reece762.github.io/strategy-microscope/

---

## 這個專案在做什麼

影片裡常有一些聽起來很有道理的規則，例如「每週四最弱，那就跳過週四」、「跌破均線就減碼」。這些規則在原本的市場（多半是中國 A 股）可能真的有效，但換一個市場、換一段時間，還有效嗎？

目前收錄 **44 個講法**，其中 **33 個**做了實際回測，**11 個**無法回測（8 個缺資料，3 個屬心法觀念）。逐條重跑，並且不只看帳面績效，還拆解它有沒有可能是假象：

- 是不是只是因為**少持倉**（少買自然波動小）？→ 用「同曝險、不擇時」的固定槓桿買進持有當基準。
- 是不是靠**少數幾天**撐起來？→ 剔除最極端的幾天後重算。
- 統計上**顯不顯著**？→ 附 t 值（t-statistic，衡量平均報酬偏離零的程度；絕對值超過 2 大約才稱得上顯著）。
- 有沒有**前視偏差**（用了當天才知道的資訊）？→ 全部信號只用前一交易日收盤。

44 個講法裡有 **33 個**能算出數字；**11 個**因為缺少資料、樣本不足，或本身就是心法觀念，只寫清楚缺什麼、為什麼做不到。

## 結論摘要

| 評級 | 條數 | 意思是什麼 |
|---|---|---|
| A | 1 | 通過雙重檢驗：55 年樣本與近 10 年樣本都勝過同曝險基準 |
| B | 11 | 帳面有改善，但證據不足以支撐實盤採用 |
| C | 7 | 效應曾經真實存在，但已衰減到無法交易 |
| D | 14 | 不成立，甚至有害 |
| — | 11 | 資料不存在、樣本不足，或屬心法觀念，無法有效檢驗 |

只有一條拿到 A：**均線×星期擇時**。但它的功勞不在「星期」，而在 20 日均線本身的趨勢過濾 —— 跌破均線就減碼，這才是回撤被砍掉的原因。

## 兩個最值得記住的否定結果

**1. 跳過週四在 BTC 上是假陽性。**
帳面上年化從 38.51% 變成 55.78%，看起來是全部測試裡最漂亮的一組。但週四平均 −0.228% 的 t 值只有 **−1.17**（不顯著）；把 476 個週四裡最差的 **5 天**剔掉，平均立刻回到 **−0.020%**，等於零。它賺的不是「每個週四都跌」，而是「剛好躲過 2020 年 3 月與 2022 年那幾次崩盤，而那幾次剛好發生在週四」。

**2. 美股的「黑色星期一」已經結束了。**
1971–1999 年，納斯達克週一平均 −0.127%（t = −4.47），完全符合傳說。但 2000 年之後變成 +0.005%（t = +0.12），效應歸零。同一條規則在 55 年樣本上是負貢獻，在近 10 年卻是正貢獻 —— 這種「換一段時間就翻轉」正是它不可交易的理由。

## 資料與假設

| 項目 | 內容 |
|---|---|
| 納斯達克綜合指數 | FRED 代碼 `NASDAQCOM`，1971-02-05 至 2026-10-21，共 14,046 個有效交易日（原始下載 14,533 列，其中 487 列當日無報價） |
| SPY / QQQ / 道瓊斯 | 日線收盤價，2016-10-19 至 2026-10-19，各約 2,512 個交易日 |
| BTC / ETH | Binance 官方公開封存，2017-08 至 2026-09，各 3,332 天 |
| 交易成本 | 美股每趟 1 bp（萬分之一）；加密貨幣每趟 5 bp |
| 股息 | 全部採價格報酬（不含股息），策略與基準兩邊一致，因此不影響「策略對基準」的比較結論 |
| 年化換算 | 美股以 252 個交易日、加密貨幣以 365 天計算 |

因為美股與加密貨幣的年化基準不同，**兩邊的夏普比率不能直接比大小**。

## 目錄結構

```
.
├── index.html            # 網站首頁（建置產物，請勿手動編輯）
├── d_*.html              # 10 個詳細頁（建置產物）
├── changelog.html        # 版本紀錄（建置產物）
│
├── run.py                # 美股：週內效應、跳過週四、均線×星期
├── btc.py                # 加密貨幣：同一組策略，7 天日曆
├── extra.py              # 只做週一、日曆窗口（12/10 前後）
├── robust.py             # 穩健性檢驗：剔除極端值、逐年拆解
├── fetch_eth.py          # 下載 ETH 日線（與 BTC 同期間）
├── prep_series.py        # 對齊各策略與基準的淨值曲線
│
├── build_page.py         # 產生全部 HTML
├── detail_tpl.py         # 詳細頁版型
├── code_snippets.py      # 用 inspect 抓實際執行的函式原始碼
│
├── data/                 # FRED 指數、Binance 月度封存（公開資料）
└── out/                  # 回測輸出（不進版控，可重新產生）
```

## 如何重新建置

需求：Python 3.12、pandas、numpy、matplotlib，以及中文字型（Noto Sans CJK）。

```bash
pip install pandas numpy matplotlib

python run.py           # 美股回測 → out/results.json
python btc.py           # 加密貨幣回測
python fetch_eth.py     # 若尚未下載 ETH 日線
python prep_series.py   # 對齊基準曲線 → out/series.json
python build_page.py    # 產生 13 個 HTML
```

新增一條策略的流程是：在對應的 `.py` 加入回測函式、在 `build_page.py` 的卡片清單加一段、重新建置。圖表、篩選標籤、可展開的程式碼都會自動生成。

## 一個刻意的設計

詳細頁底部的「顯示代碼」不是另外抄一份示範程式碼，而是建置時用 Python 的 `inspect.getsource` 從**實際跑出這些數字的函式**擷取原始碼。所以只要改了回測參數，重新建置後頁面上的程式碼就會跟著變，不可能出現「頁面寫的跟實際跑的不同」。

## 發布方式

推送至 `main` 分支後，GitHub Actions 會自動把 **13 個 HTML** 發布到 GitHub Pages。原始資料（`data/`）與 Python 腳本留在版本控制裡，但**不會**被網站提供下載。

## 已知限制

- 股息未計入。若比較含股息的總報酬，絕對數值會更高，但策略與基準的相對結論不變。
- SPY / QQQ 樣本只有 10 年，任何「近 10 年有效」的結論都可能是這段時期的運氣。
- 加密貨幣的歷史只有 9 年，且僅涵蓋一次完整的牛市與熊市循環。
- 日曆效應本質上是多重檢定問題：測了 16 個窗口組合，總會有幾個 t 值超過 2。已盡量標註哪些是多點同時顯著、哪些是單點雜訊。
- 未模擬滑價、借券成本、稅賦與資金費率。
