直接照做：年化 5.62%，買進持有 10.55%，淨值 21 倍 vs 267 倍。 回撤從 −77.9% 惡化到 −82.3%（跳過週四等於少了 20% 的修復日）。

但這個比較還不夠公平：跳過週四只持倉 79.9% 的時間。所以我又算了「同樣 80% 曝險、完全不擇時」的基準：年化 8.70%、回撤 −68.9%。策略仍然輸，而且回撤更差。

為什麼會這樣？ 因為在美股 55 年裡，週四的平均報酬是 正的（+0.078%）。跳過一個正報酬的日子，等於每週主動放棄一點收益。他的策略在 A 股有效，前提是 A 股週四真的為負（他實測 −0.10%）；這個前提在美股不存在。

判定：不成立。在美股，這是「每週刻意漏掉一天正報酬」，長期年化少一半。
依據：納斯達克 1971–2026，14,046 日；成本每趟 1bp。同曝險基準為每日再平衡的固定槓桿買進持有。
run.py · skip_thursday() 跳過週四，其餘每天持有。美股成本每趟 1 bp。 
# 執行環境：Python 3 + pandas / numpy
# 資料：日線收盤價，欄位 close
# 重點：第 i 根的持倉只用第 i-1 根收盤前的資訊決定，無前視（no look-ahead）
# 成本：美股每趟 1 bp（萬分之一），加密每趟 5 bp

def skip_thursday(df, cost_bp=1.0):
    """Hold every day except Thursday. Deterministic, no look-ahead."""
    r = df['close'].pct_change().fillna(0)
    pos = pd.Series((r.index.dayofweek != 3).astype(float), index=r.index)
    turnover = pos.diff().abs().fillna(0)
    ret = pos * r - turnover * cost_bp / 1e4
    return (1 + ret).cumprod()
