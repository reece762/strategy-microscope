它為什麼有效？ 這其實不是「星期效應」的功勞，而是 20 日均線本身的趨勢過濾：跌破均線就大幅減碼，在 2000 年和 2008 年那種崩盤裡把回撤砍掉一半。星期規則只是決定「減碼時往哪天躲」，屬於裝飾。真正有用的部分是他的均線擇時，不是他的日曆理論。

代價：持倉只有 41%，長期報酬明顯低於滿倉（55 年年化 7.30% vs 10.55%）。適合想降低回撤、能接受少賺的人。

判定：有效，但功勞在均線不在星期。風險調整後明顯改善，代價是報酬變低。
依據：兩段樣本（55 年 / 10 年）皆勝同曝險基準；信號只用前一日收盤，無前視。
run.py · regime_strategy() 均線×星期：用前一日收盤與 MA20 判斷多空，再依星期決定持倉。 
# 執行環境：Python 3 + pandas / numpy
# 資料：日線收盤價，欄位 close
# 重點：第 i 根的持倉只用第 i-1 根收盤前的資訊決定，無前視（no look-ahead）
# 成本：美股每趟 1 bp（萬分之一），加密每趟 5 bp

def regime_strategy(df, ma_n=20, cost_bp=1.0):
    """His 均线符合策略.

    Bull (yesterday's close > MA20): hold into Mon/Fri, flat into Tue/Thu,
    carry state on Wed. Bear: hold into Tue/Wed, flat into Mon/Thu, carry on Fri.
    Position for bar i uses only information available at close of bar i-1.
    """
    close = df['close']
    ma = close.rolling(ma_n).mean()
    r = close.pct_change().fillna(0)
    wd = r.index.dayofweek.to_numpy()
    c = close.to_numpy()
    m = ma.to_numpy()

    pos = np.zeros(len(df))
    prev = 0.0
    for i in range(len(df)):
        if i < ma_n + 1 or not np.isfinite(m[i - 1]):
            pos[i] = 0.0
            prev = 0.0
            continue
        bull = c[i - 1] > m[i - 1]
        d = wd[i]
        if bull:
            if d in (0, 4):
                p = 1.0
            elif d in (1, 3):
                p = 0.0
            else:
                p = prev
        else:
            if d in (1, 2):
                p = 1.0
            elif d in (0, 3):
                p = 0.0
            else:
                p = prev
        pos[i] = p
        prev = p

    ps = pd.Series(pos, index=r.index)
    turnover = ps.diff().abs().fillna(ps.iloc[0])
    ret = ps * r - turnover * cost_bp / 1e4
    return (1 + ret).cumprod(), ps
